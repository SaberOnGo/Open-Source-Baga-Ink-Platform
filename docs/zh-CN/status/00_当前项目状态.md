## 6. Kindle Reference Platform 状态

Kindle 是第一份 Reference Platform Port。

已明确的架构边界包括：

```text
Baga Ink Client
→ jailbreak/bootstrap route when needed
→ Homebrew-ready
→ KPM where compatible, MRPI/legacy envelope where necessary
→ Baga Ink Platform
→ IKP Package Manager
→ lifebook.ikp / other Baga Apps
→ Kindle Home Entry
```

同时冻结：

- `.ikp` 不转换成 `.kpkg`；
- KPM 管 Native Baga Platform，IKP Package Manager 管 Baga Apps；
- KPM 未安装 ≠ KPM 不兼容；
- KOReader / koreader-base / FBInk 为内部 Adopted Components，不是 LifeBook API；
- LifeBook 不直接依赖 Kindle / KOReader Private API；
- Kindle Device Adapter 最大化复用成熟实现；
- `kindlehf` 作为第一条真实 Bring-up 路线；
- Probe IKP 应先于完整 LifeBook 验证 Platform。

当前工程计划已经建立：

```text
docs/plans/platform-ports/kindle/
```

并具有 Task Design / Version / Execution Prompt / CI Guard 规则。

### 尚未完成

```text
platform/adapters/kindle/
KindleAdapterFactory
真实 Device Profiles / Quirk Sets
Display/Input/Storage/Lifecycle/Power bindings
pinned KOReader/FBInk product integration
real-device Adapter Contract Tests
Base BICTS
real baga-probe.ikp on Kindle
```

因此：

> **架构准备完成 ≠ Kindle 产品实现完成。**
