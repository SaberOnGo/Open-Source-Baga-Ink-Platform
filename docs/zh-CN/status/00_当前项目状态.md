## 4. Kindle

Kindle 是第一份 Reference Platform Port。

总体方向：

```text
Client / bootstrap
→ Homebrew-ready device
→ KPM 或已验证 legacy installer envelope
→ Baga Ink Platform
→ IKP Package Manager
→ lifebook.ikp / Baga Apps
→ Kindle Home Entry
```

重要边界：

- `.ikp` 不转换为 `.kpkg`；
- KPM 管 Native Platform，IKP Package Manager 管 Baga Apps；
- KOReader / koreader-base / FBInk 是成熟内部实现来源，不是 LifeBook API；
- Kindle Adapter 应保持薄，最大化复用成熟机制；
- Reader/UI、Jailbreak Route、KPM/MRPI、Home Entry 不属于 Device Adapter 根契约；
- 第一条真机 Bring-up 先选代表性 `kindlehf`，先跑 Probe IKP，再做完整 LifeBook。

尚未完成：

```text
platform/adapters/kindle/
KindleAdapterFactory
真实 Device Profiles / Quirk Sets
Base Display/Input/Storage/Lifecycle/Power bindings
Pinned Product Integration
真机 Adapter Contract Tests
Base BICTS
真机 baga-probe.ikp
```
