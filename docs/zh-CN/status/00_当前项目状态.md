## 5. Kindle Reference Platform 状态

Kindle 是第一份 Reference Platform Port。

已冻结总体方向：

```text
Baga Ink Client
→ 需要时 jailbreak/bootstrap
→ Homebrew-ready device
→ KPM compatible 时走 KPM；必要时走 MRPI/legacy envelope
→ Baga Ink Platform
→ IKP Package Manager
→ lifebook.ikp / other Baga Apps
→ Kindle Home Entry
```

重要决策：

- `.ikp` 不转换为 `.kpkg`；
- KPM 管 Native Baga Platform，IKP Package Manager 管 Baga Apps；
- KPM 未安装与 KPM 不兼容是两件事；
- KOReader / koreader-base / FBInk 是内部成熟能力来源，不是 LifeBook API；
- LifeBook 不直接依赖 Kindle / KOReader Private API；
- Kindle Device Adapter 最大化复用成熟机制；
- `kindlehf` 作为第一条代表性真机 Bring-up 路线；
- 先用 Probe IKP 验证 Platform，再做完整 LifeBook 产品闭环。

工程计划：

```text
docs/plans/platform-ports/kindle/
```

尚未实现：

```text
platform/adapters/kindle/
KindleAdapterFactory
真实 Device Profiles / Quirk Sets
Display/Input/Storage/Lifecycle/Power bindings
pinned KOReader/FBInk product integration
真机 Adapter Contract Tests
Base BICTS
真机 baga-probe.ikp
```

架构准备完成不等于 Kindle 产品实现完成。

## 12. 最终状态判断原则

> **文档存在不等于实现完成；代码能编译不等于 Compatible；某个设备成功启动一次不等于 Stable。**

Baga Ink 的状态最终必须由：

```text
Code
+ Machine-readable Spec
+ Tests
+ Device Evidence
+ Conformance
+ Approved Public Docs
```

共同说明。
