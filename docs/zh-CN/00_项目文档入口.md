## 1. 第一次进入项目怎么读？

长期事实来源是 `main` 中的 Code、Tests、Machine-readable Spec 与 Approved Public Docs。

推荐顺序：

```text
README.zh-CN.md
  ↓
docs/zh-CN/status/00_当前项目状态.md
  ↓
docs/zh-CN/standards/00_规范总览.md
  ↓
与任务相关的 Design / Reference App / Plan
  ↓
docs/zh-CN/governance/00_开发治理.md
```

AI / 自动化贡献者还必须阅读 `AGENTS.md`。

## 5. 工程计划不强制全文翻译

`docs/plans/` 是工程施工区，不是 Public Protocol Authority。

特别是：

```text

```

可以继续中文优先，使用已治理的双语语义文件名、Versioned Task Design 与 Execution Prompt。

任何外部实现者必须长期依赖的稳定结论，MUST 提升回 Localized Standards / Design / Reference Apps / Governance / Status。
