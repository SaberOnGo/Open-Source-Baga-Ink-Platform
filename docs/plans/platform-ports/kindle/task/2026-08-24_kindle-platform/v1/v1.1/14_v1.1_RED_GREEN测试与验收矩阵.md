# v1.1 RED / GREEN 测试与验收矩阵

**职责**: 规定每个 Batch 在实现前应看到什么失败、实现后必须看到什么通过，避免“代码写完但没有证据”的完成判断。

---

## 1. 总体原则

```text
RED
→ 证明测试能够捕获缺失能力/错误行为

GREEN
→ 证明实现满足当前 Contract/Task Gate

REAL DEVICE
→ 证明 host/mock 无法替代的 Kindle 行为
```

测试通过不自动等于 Baga Ink Compatible；正式兼容结论仍按 BICTS。
