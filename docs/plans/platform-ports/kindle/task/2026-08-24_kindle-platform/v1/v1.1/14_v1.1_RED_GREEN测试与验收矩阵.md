# v1.1 RED / GREEN 测试与验收矩阵

**职责**: 规定每个 Batch 在实现/设备操作前应看到什么失败，完成后必须看到什么通过，避免“做过步骤但没有证据”的完成判断。

---

## 1. 总体原则

```text
RED
→ 证明当前能力/设备状态尚未满足 Gate

GREEN
→ 证明实现或设备状态满足当前 Contract/Task Gate

REAL DEVICE
→ 证明 host/mock 无法替代的 Kindle 行为
```

测试通过不自动等于 Baga Ink Compatible；正式兼容结论仍按 BICTS。

## 2. Batch 0 — Stock → Homebrew-ready

| Area | RED | GREEN | Evidence |
|---|---|---|---|
| firmware state | stock 5.16.3 but OTA exposed | firmware still 5.16.3 after preparation/jailbreak | Device Info without unique identifiers |
| OTA risk | ~12.53 GB free / Wi-Fi could update | Airplane Mode + pending OTA removed + filler leaves ~50–90 MB before jailbreak | storage/filler record |
| route | no current route confirmation | current KindleModding Wizard agrees with WinterBreak2 | local route result, public summary only |
| jailbreak | `;log` does not confirm jailbreak | `;log` confirms jailbreak | manual/device evidence |
| Homebrew | KPM unavailable | KPM invocation works | command/result evidence |
| OTA block | automatic updates not proven blocked | current post-jailbreak OTA block verified | status evidence |
| recovery | reboot/Home/USB-MTP not rechecked | reboot + Home + basic reading + USB/MTP smoke pass | manual summary |

Batch 0 GREEN 必须满足 `20` 和 `15`，不能只以“看到 jailbreak 文本”为完成条件。

## 11. Evidence 命名

每个 Batch 的 summary 至少记录：

```text
commit SHA
commands/tests or device operations
precondition state
RED result
GREEN result
device facts when applicable
artifact digest
logs/screenshots/manual evidence path
known warnings
remaining blockers
```

公开证据必须移除完整序列号、MAC、账号信息。真机证据与恢复格式见 `15`。
