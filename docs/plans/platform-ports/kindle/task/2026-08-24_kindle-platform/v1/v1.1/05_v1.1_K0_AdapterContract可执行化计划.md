# v1.1 K0：Adapter Contract 可执行化计划

**目标**: 把 Standard 07 的 Base Device Adapter Contract 变成机器可读、可生成、可 Mock、可自动测试的工程闭环。

---

## 1. Scope

Base Mandatory：

```text
DeviceDescriptor / identity
CapabilitySnapshot
Display
Input
Storage
Lifecycle
Power
root init / self-test / shutdown
stable errors / events
```

产物：

```text
spec/adapter/*
frozen contract snapshot
first-party generated bindings
Mock/Headless Adapter
Adapter Contract Test harness
compatibility/reproducibility CI
```

---

## 2. 固定边界

1. Markdown Standard 07 仍是语义权威；IDL 不成为第二套协议。
2. IDL 不写 Kindle/Android 私有对象。
3. v1.1 不建立 Adapter daemon/RPC/Binder/JSON bridge。
4. generated Rust/C/Kotlin 是当前 first-party binding targets，不是实现语言白名单。
5. 通用 Lua codegen 不作为 Kindle K0/K1 前置条件。

---

## 3. 实施步骤

```text
K0-1  定义 schema / loader
K0-2  固化 root/descriptor/capability/error/event core types
K0-3  固化 display/input/storage/lifecycle/power IDL
K0-4  建立 frozen v0.1 snapshot
K0-5  deterministic codegen
K0-6  Mock Adapter
K0-7  shared Contract Tests
K0-8  compatibility + reproducibility checks
K0-9  CI gate
```

---

## 4. RED 基线

实现前至少建立失败测试证明：

```text
missing required subsystem rejected
unknown type/reference rejected
duplicate IDs rejected
generated output absent/non-deterministic
a breaking frozen-contract change detected
Mock cannot satisfy Base Contract before implementation
```

---

## 5. GREEN Gate

K0 完成必须证明：

```text
[ ] IDL 能表达 Base Mandatory Contract
[ ] current/frozen 可比较
[ ] codegen repeated run byte/logically stable
[ ] Mock Adapter 通过 Base Contract Tests
[ ] error/event semantics 与 Standard 07 一致
[ ] CI 能阻止 breaking drift
[ ] Kindle-specific implementation detail 未进入通用 IDL
```

K0 通过不等于任何真实 Kindle 已 Compatible。

---

## 6. Write Scope

允许主要修改：

```text
spec/adapter/**
sdk/adapter/**
tools/baga-adapter-codegen/**
tests/adapter_contract/**
tests/adapter_mock/**
相关 CI
```

K0 不写 `platform/adapters/kindle/` 的真实硬件 backend；K1 的 upstream build 工作可并行但分别验收。
