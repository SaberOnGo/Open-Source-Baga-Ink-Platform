## 3. 从 Batch 0 开始：Stock → Homebrew-ready

未指定 Batch 时必须先执行 Batch 0，不得先写需要真机 Homebrew 的 Baga 代码。

固定步骤和 route 由 `20` 定义。实现 Agent 必须：

```text
1. reconfirm firmware is still 5.16.3
2. enable/keep Airplane Mode
3. back up required visible user/development data
4. inspect/remove visible pending OTA/update files
5. manually fill 11th-gen storage to about 50–90 MB free
6. locally use KindleModding Jailbreaking Wizard to confirm route
7. proceed only when Wizard/current upstream agrees with WinterBreak2
8. stage and run current official WinterBreak2
9. after success return to Airplane Mode
10. verify `;log`
11. verify KPM availability
12. verify OTA blocking
13. verify reboot / Kindle Home / USB-MTP
14. save red/green device evidence with unique identifiers redacted
```

WinterBreak2 失败时，只按 `20` 的 predefined fallback Gate 处理。不得临时改用 Sanctuary/SpringBreak/Véra/AdBreak/Nosebleed 等其他方法。

Batch 0 GREEN 之前，不得宣称设备 Homebrew-ready。
