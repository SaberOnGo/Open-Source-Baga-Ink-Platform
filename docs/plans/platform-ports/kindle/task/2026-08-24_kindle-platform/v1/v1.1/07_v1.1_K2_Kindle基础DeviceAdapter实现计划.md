# v1.1 K2：Kindle 基础 Device Adapter 实现计划

**目标**: 在 K0 Contract 与 K1 substrate 都通过后，实现一份薄 Kindle Reference Adapter。

```text
KOReader / koreader-base / FBInk / Kindle OS / validated Homebrew
→ thin binding + normalization
→ Baga Device Adapter Contract
```

---

## 1. Dependency Gate

进入功能实现前必须已有：

```text
K0 machine Contract + Contract Tests baseline
K1 pinned kindlehf substrate + direct-entry evidence
```

Gate 未通过时仅允许 profile/fixture/backend research。

---

## 2. Scope

```text
K2-1  KindleAdapterFactory + conservative probe
K2-2  DeviceDescriptor
K2-3  Device Profile selection
K2-4  Quirk Set selection
K2-5  Capability detection
K2-6  DisplayAdapter
K2-7  InputAdapter
K2-8  StorageAdapter
K2-9  LifecycleAdapter
K2-10 PowerAdapter
K2-11 error/event normalization
K2-12 QUICK/INTERACTIVE self-test
K2-13 Kindle Adapter Contract Tests
```

Base Capability：

```text
display.basic
input.navigation
storage.app_sandbox
power.sleep_wake
platform.lifecycle
```

---

## 3. 默认 backend / 语言矩阵

```text
factory/probe/profile/quirk/capability → Lua first
display                           → KOReader Lua wrapper first
input                             → KOReader Lua wrapper
storage policy                    → Lua first + mature native libs
lifecycle                         → KOReader/Kindle event Lua wrapper
power                             → Lua wrapper first
FBInk                             → existing C/native
```

允许混合语言，不要求 Adapter 单语言化。

---

## 4. 明确禁止优先重写

```text
framebuffer stack
evdev/input stack
reader engine
network stack
power daemon
KOReader device knowledge
FBInk implementation
```

只有现有成熟机制确实无法满足 Contract 且有证据时才增加 narrow replacement/binding。

---

## 5. Profile / Quirk 分层

必须分开：

```text
Native Build Target
→ how native code is built

Device Profile
→ known model + firmware facts/capabilities/backend preferences

Quirk Set
→ exact corrections required by specific combinations
```

Quirk 必须有 match range 与测试证据。

---

## 6. RED Gate

先证明未实现 Adapter 会失败：

```text
unknown firmware does not get Stable capability by assumption
navigation event not normalized
storage escape attempt rejected by expected contract
sleep/wake mapping missing
backend raw error not normalized
profile/quirk mismatch detected
```

---

## 7. GREEN Gate

至少证明：

```text
[ ] exact conservative probe
[ ] descriptor complete
[ ] Base capability consistent with backend evidence
[ ] display geometry/refresh safe
[ ] navigation normalized
[ ] storage containment holds
[ ] lifecycle + sleep/wake normalized
[ ] profile and quirk separated
[ ] backend errors normalized
[ ] self-test report available
[ ] Adapter Contract Tests pass on target
```

Adapter tests 通过仍不等于整机 Baga Ink Compatible；正式兼容结论还需要 BICTS。
